## 3. Стек технологий
- **Обработка данных:** Python, `Polars` (zero-copy в Arrow, высокая производительность).
- **Хранение данных:** `Parquet` (партиционированное локальное хранилище).
- **Аналитические запросы:** `DuckDB` (локальный SQL поверх Parquet без поднятия серверов).
- **Инфраструктура:** Никаких тяжелых серверных баз (PostgreSQL / TimescaleDB) для этапа исследований.
- **Управление зависимостями:** `uv` (установлен в `/opt/homebrew/bin/uv`).

## 4. Рынок и данные
- **Биржа:** MOEX (Московская биржа).
- **Источник данных №1:** основной источник - Московская биржа (https://iss.moex.com/iss/)
- **Источник данных №2:** API Algopack (используется для получения данных).
- **Источник данных №3:** API «Т-Инвестиции» (T-Bank / Tinkoff Invest API).
- **Инструменты:** фьючерсы.

## 8. Архитектура (`src/`)
- `core/` — базовые сущности, календарь сессий MOEX, API-клиенты.
- `data/` — сбор, очистка данных и склейка фьючерсов.
- `features/` — расчет признаков (факторов) и их статистический отбор.
- `dataset/` — разметка таргетов, разбиение выборки (train/test) и подготовка матриц.
- `models/` — обучение и валидация моделей (линейные, бустинг, нейросети).
- `backtest/` — тестирование стратегий с учетом комиссий и проскальзываний.
