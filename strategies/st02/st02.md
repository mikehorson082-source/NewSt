### 🎯 Шаг 1. Сбор данных

**Что нужно:** 5-минутные данные по фьючерсу Si (сделки и стакан).

**Источник:** ISS API Московской биржи. Данные по фьючерсам доступны через эндпоинт `https://iss.moex.com/iss/analyticalproducts/futoi/securities/si` в форматах CSV, JSON и XML. Для VPIN нужны не позиции (FUTOI), а **реестр сделок** (`/trades`) и **котировки** (`/orderbook`), поскольку VPIN рассчитывается на основе потока заявок.

**Период:** Начните с одного года — например, 2024. Этого достаточно, чтобы понять, работает ли сигнал, и при этом объём данных manageable.

**Формат:** Вам нужны поля `price`, `volume`, `side` (buy/sell) для каждой сделки. `side` определяется по правилу тика (сделка по цене выше предыдущей — buy, ниже — sell).

### 📐 Шаг 2. Реализация VPIN

VPIN измеряет дисбаланс объёма покупок и продаж в рамках **объёмных баров** (buckets), а не временных. Формула: `VPIN = mean(|buy_vol − sell_vol| / (buy_vol + sell_vol))` по скользящему окну из N бакетов.

**Код (базовая реализация):**

```python
import numpy as np
import pandas as pd

def vpin(buy_vol, sell_vol):
    imbalance = np.abs(buy_vol - sell_vol)
    total = buy_vol + sell_vol
    return imbalance / np.where(total == 0, 1, total)
```

Затем агрегируйте сделки в объёмные бары: накапливайте объём до достижения заданного размера бакета, фиксируйте `buy_vol` и `sell_vol` в каждом бакете.

---

### ⚙️ Шаг 3. Калибровка параметров

Два ключевых параметра, которые определят чувствительность сигнала:

**Размер бакета (bucket size).** Подбирается так, чтобы получалось разумное количество бакетов в день. Для ликвидных FX-пар с миллиардными объёмами рекомендуется 1M за бакет. Для Si на MOEX объёмы другие — начните с такого размера, чтобы в день получалось **50–100 бакетов**.

**Скользящее окно (rolling window).** Стандартное значение — **50 бакетов**. Это окно, по которому усредняется VPIN.

**Важно:** VPIN чувствителен к размеру бакета. Количество бакетов в день (β) оказывает **наибольшее влияние на частоту ложных срабатываний**, помимо самого порога. Поэтому калибровку нужно делать аккуратно: проверьте 2–3 размера бакета и посмотрите, как меняется число сигналов.

---

### 📊 Шаг 4. Определение порога токсичности

VPIN нормирован от 0 до 1. В литературе используются разные пороги. Easley, López de Prado и O’Hara в ранних тестах использовали **0.9** как порог для Φ(x). На практике для VPIN как такового часто используют уровни: **<0.25 — низкая токсичность, 0.25–0.5 — средняя, 0.5–0.75 — высокая**.

**Рекомендация:** Начните с порога **0.5–0.6** и посмотрите, сколько сигналов он даёт. Если сигналов слишком много (больше 10–15 за год на Si), поднимите порог. Если слишком мало — снизьте.

---

### 📈 Шаг 5. Тестирование сигнала

**Гипотеза:** VPIN выше порога предсказывает **рост волатильности** на следующих 5–20 периодах (5-минутных).

**Что считать:**

1. **Событие:** VPIN пересекает порог снизу вверх.
2. **Форвардная волатильность:** realized volatility за следующие 5, 10, 20 периодов.
3. **Сравнение:** средняя форвардная волатильность после сигнала vs. средняя волатильность без сигнала (baseline).

Если после сигнала волатильность статистически значимо выше baseline — сигнал работает.

**Дополнительно:** проверьте, предсказывает ли VPIN **направление** движения. Литература говорит, что VPIN предсказывает волатильность, но не направление. Если направление не предсказывается — это нормально, используйте VPIN как сигнал на **изменение режима**, а не как сигнал на вход в лонг/шорт.

### 💸 Шаг 6. Бэктест с комиссиями

**Комиссии на Si.** Биржевой сбор для валютных контрактов составляет **0.0014% от расчётной цены** (примерно 0.81 руб. при цене Si ≈ 57,576). Брокерская комиссия обычно **0.5–1 руб. за контракт** у большинства брокеров. В сумме закладывайте **~1.5–2 руб. за контракт** (вход + выход = 3–4 руб.).

**Проскальзывание.** На Si ликвидность высокая, но на 5-минутном горизонте закладывайте **1 тик** на сделку.

**Стратегия для теста:** Поскольку VPIN предсказывает волатильность, а не направление, простейший вариант — **стрэддл-подобная логика**: при сигнале VPIN открывать позицию в направлении последнего импульса с узким стопом, рассчитывая на расширение волатильности. Альтернатива: использовать VPIN как **фильтр** — не входить в рынок, когда VPIN ниже порога (низкая токсичность = низкая волатильность = мало возможностей).

### 📋 Шаг 7. Анализ результатов

**Метрики для каждого варианта:**
- Количество сигналов за год
- Средняя форвардная волатильность после сигнала vs. baseline
- Винрейт (если торгуете направленно)
- Средняя доходность на сделку после комиссий
- Максимальная просадка

**Критический вопрос:** Устойчив ли эффект? Если VPIN даёт 20 сигналов за год и 15 из них предсказывают рост волатильности — это может быть случайностью на малой выборке. Если 100 сигналов и 65 предсказывают — это уже статистически осмысленно.

---

### ⚠️ Ключевое ограничение

Академические работы показывают, что VPIN имеет **слабую предсказательную силу** относительно будущей краткосрочной волатильности. Это означает, что даже если вы найдёте эффект, он может быть **экономически незначимым** после вычета комиссий. На 5-минутном горизонте комиссии съедают значительную часть прибыли. Поэтому первый тест должен быть именно на **предсказание волатильности** (без торговли), и только если эффект сильный — переходить к бэктесту с комиссиями.

Начните с Шага 1–2 и посмотрите на данные. Если VPIN на Si ведёт себя осмысленно (растёт перед всплесками волатильности) — двигайтесь дальше. Если нет — это тоже результат.
