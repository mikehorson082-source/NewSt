# Кабинет исследователя (Researcher Cabinet)

Архитектурная концепция и план веб-пульта управления данными, экспериментами и стратегиями для проекта **NewSt**.

---

## Проблема и предпосылки

Когда проект разрастается:
1. **Держать в голове статус данных невозможно:** *«какие фьючерсы скачаны, за какие годы есть минутки, обновлены ли клиринги до вчерашнего дня»* — помнить всё в деталях физически нереально.
2. **Ручные заметки устаревают:** Вести вручную [info.md](info.md) и текстовые файлы отнимает кучу времени, а информация быстро теряет актуальность.
3. **Сложно сравнивать гипотезы:** Логировать отброшенные идеи и параметры стратегий в обычных текстовых файлах неудобно — их тяжело фильтровать и сопоставлять между собой.
4. **Опасность переделки структуры:** Если не продумать интерфейс взаимодействия заранее, при попытке «прикрутить веб-морду» позже придётся болезненно перекраивать функции и расчетное ядро.

## 1. Как встроить пульт, чтобы НЕ сломать структуру проекта?

В правильной архитектуре веб-пульт — это **не замена** коду, а просто **удобное окно** в вашу систему.

Движок и интерфейс строго разделены:

```
NewSt/
├── src/                  # Наш чистый расчетный движок (Python)
│   ├── core/             # Календарь MOEX, базовые типы
│   ├── data/             # Сбор, склейка, инвентаризация данных
│   └── backtest/         # Симулятор, паспорта, расчет рисков
├── data/                 # Локальные Parquet-файлы (наше хранилище)
├── st01/, st02/          # Папки стратегий (их конфиги и параметры)
│
└── app/                  # ПУЛЬТ УПРАВЛЕНИЯ (Web / Mobile)
    ├── api/              # Легковесный FastAPI (Python)
    └── frontend/         # React-приложение на Vite (адаптировано под телефон)
```

### Почему ничего не придётся переделывать:
* Скрипты в `src/` остаются независимыми модулями, ничего не знающими о вебе.
* Бэкенд пульта `app/api` просто импортирует функции из `src/` и возвращает результат в JSON:
  * `/api/data/status` — вызывает функцию инвентаризации и отдаёт статус всех файлов.
  * `/api/data/update` — запускает фоновую докачку нужного рынка.
  * `/api/strategies` — отдаёт таблицу всех протестированных вариантов.
* Любое действие по-прежнему можно запускать из консоли через CLI **или** нажимать кнопки на телефоне — движок работает абсолютно одинаково.

## 2. Стек технологий

* **Фронтенд:** `React + Vite`
  * Адаптивная верстка (Mobile First) для комфортной работы со смартфона.
  * Формат **PWA (Progressive Web App)**: возможность добавить сайт на домашний экран iPhone/Android в виде отдельного приложения с иконкой.
  * Быстрые графики (TradingView Lightweight Charts / интерактивный SVG).
* **Бэкенд:** `FastAPI (Python)`
  * Единый процесс: FastAPI сам отдаёт скомпилированный фронтенд (`dist/`) и обрабатывает API-запросы.
  * **Отдельный веб-сервер (Nginx / Node.js) не требуется.**
* **Развёртывание и перенос (Docker):**
  * Проект упаковывается в единый компактный Docker-образ через *Multi-stage build* (Node.js компилирует фронтенд и удаляется, в финальном контейнере работает только легковесный Python).
  * Данные `data/` подключаются через Docker Volume, сохраняясь при любых обновлениях.
  * Запуск на любом хостинге/VPS за 400–600 ₽/мес в 1 команду: `docker compose up -d`.

## 3. Функциональные экраны Кабинета исследователя

### Экран 1: «Инвентарь данных» (Data Catalog) — закрывает проблему с `info.md`
Таблица, которая сканирует диск автоматически в реальном времени:
* **Справочники:** `margin_rates` (2018–2026, 24 рынка), `rates_moex_clearing` (2013–2026), статус: *Актуален (зелёный)*.
* **Ряды фьючерсов:** Brent (с 2020 по 2026, 44 контракта, 1 216 дней, 0 пропусков).
* **Кнопка в 1 клик:** *«Обновить всё с биржи»* или *«Докачать конкретный фьючерс»*.
* *Больше никогда не придётся вручную вспоминать, что скачано, а что нет.*

### Экран 2: «Реестр стратегий и гипотез» (Experiment Tracker)
Таблица всех экспериментов и версий:
* Название: `st01_breakout_v1`, `st01_mean_reversion`.
* Рынки: MIX, Brent, Gold, CNY.
* Результат: Sharpe, Доходность %, Макс. просадка %, Процент прибыльных.
* Статус и заметка:
  * 🔴 *«Отброшена: просадка 22% в 2022 году»*
  * 🟡 *«В исследовании: шаг 3.2»*
  * 🟢 *«Одобрена для walk-forward»*

### Экран 3: «Витрина графиков»
* Интерактивные графики (ГО, спреды курсов, склейки фьючерсов, кривая эквити и просадки), которые удобно смотреть лёжа на диване со смартфона.
